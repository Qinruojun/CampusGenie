# Vue3 语法
.vue文件里面同时包含三种东西
```
<template>
<!--这里写页面结构，长得很像HTML-->
</template>

<script setup>
    //这里写JavaScript 逻辑
</script>
<style scoped>/*scoped 表示这个CSS样式只影响当前这个组件，不影响其他组件*/
    /*这里写CSS样式*/
</style>
```
## style
style部分可以给 `<template>` 里对应 class="类名" 的元素设置样式
如：

``` vue
.logo {
}
```
也可以给标签设置样式如`<botton>`，不用加`.`
```
button {
  border: none;
  padding: 10px 18px;
  border-radius: 10px;
  cursor: pointer;
}
```
对应代码
```
<button>登录</button>
<button>注册</button>
```
如果只想给类中的某个元素设置样式可以`.{classname} {element}`
```
.hero h1 {
  font-size: 34px;
}
<div class="hero">
  <h1>校园生活百宝箱</h1>
</div>
```
## template
标签含义：
所有标签都可以加class={classname}也可以不加，加class的好处是可以通过唯一的类名单独控制某个标签，如单独设定style样式
### 常见标签：
| 标签          | 作用         | 你代码里的用途           |
| ----------- | ---------- | ----------------- |
| `<div>`     | 普通容器、盒子    | 包住页面、Logo、卡片、聊天消息 |
| `<header>`  | 页面头部       | 顶部导航栏             |
| `<nav>`     | 导航区域       | 放“智能问答、知识库、校园资讯”  |
| `<a>`       | 链接         | 导航菜单项             |
| `<button>`  | 按钮         | 登录、注册、发送、分类按钮     |
| `<main>`    | 页面主体内容     | 包住左侧内容和右侧边栏       |
| `<section>` | 页面中的一个内容区域 | 左侧主内容区域           |
| `<aside>`   | 侧边栏        | 右侧热门问题、分类浏览       |
| `<h1>`      | 一级标题       | “校园生活百宝箱”         |
| `<h3>`      | 三级标题       | “热门问题”“分类浏览”      |
| `<p>`       | 段落文字       | 说明文字、问题列表         |
| `<input>`   | 输入框        | 输入你的问题            |
### 事件(如鼠标点击)
Vue事件写法：
```
<标签 @事件名="函数名">内容</标签>
```
---事件的处理函数就定义在`<script setup>`当中
#### 常用鼠标事件
| 事件            | 作用   |
| ------------- | ---- |
| `@click`      | 点击   |
| `@dblclick`   | 双击   |
| `@mouseenter` | 鼠标移入 |
| `@mouseleave` | 鼠标移出 |
| `@mouseover`  | 鼠标经过 |
| `@mousedown`  | 鼠标按下 |
| `@mouseup`    | 鼠标松开 |

#### 常用输入事件
| 事件        | 作用         |
| --------- | ---------- |
| `@input`  | 输入框内容变化时触发 |
| `@change` | 内容改变并确认后触发 |
| `@focus`  | 输入框获得焦点    |
| `@blur`   | 输入框失去焦点    |

## script / CSS
`@media`是CSS原生的[媒体查询]语法，用来做响应式布局，即在不同屏幕尺寸(收集，平板，电脑)下显示不同的样式
``` 
.box {
  width: 100%;
  background: blue;
}
/* 意思是在屏幕>768px时生效 */
@media (min-width:768px){
    .box{
        width:50%;
        background: red;
    }
}
```
