# Vue3 语法
.vue文件里面同时包含三种东西
```
<template>
<!--这里写页面结构，长得很像HTML-->
</template>

<script setup>
    //这里写JavaScript 逻辑
</script>
<style scoped>/*scoped 表示这个CSS样式只影响当前这个组件，不影响其他组件*/
    /*这里写CSS样式*/
</style>
```
## style
style部分可以给 `<template>` 里对应 class="类名" 的元素设置样式
如：

``` vue
.logo {
}
```
也可以给标签设置样式如`<botton>`，不用加`.`
```
button {
  border: none;
  padding: 10px 18px;
  border-radius: 10px;
  cursor: pointer;
}
```
对应代码
```
<button>登录</button>
<button>注册</button>
```
如果只想给类中的某个元素设置样式可以`.{classname} {element}`
```
.hero h1 {
  font-size: 34px;
}
<div class="hero">
  <h1>校园生活百宝箱</h1>
</div>
```
