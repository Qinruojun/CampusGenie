# CSS基本语法
```
选择器 {
    属性名:属性值;
    属性名:属性值;
}
\*如*\
.card{
    background: white;
    padding: 24px;
    border-radius: 20px;
}
```
选择器：vue里面`<template>`的类名要加`.`,如`.card`如果是标签名则不用加`.`,如`botton`
